# 0.2.0：常用服务器、应用分流与系统诊断

## What changed

- Flutter 增加常用服务器页、应用分流页、系统与连接诊断页；仍保持连接 / 设备 /
  设置三个底部入口，不把管理后台复制到手机首页。长列表的保存动作固定在底部。
- Kotlin 的 `ProfileStore` 成为偏好的唯一读写入口。当前项和列表在一次提交中
  持久化；旧单服务器键只在首次迁移读取，成功提交后删除。不保留第二套运行时实现。
- 每个规范控制面根地址对应一组设备名、子网、重连与应用偏好，最多保存 16 个。
  添加、切换、移除必须处于断开状态，且没有未结束的系统 VPN 授权请求。
- 使用 Android VpnService 的允许或排除清单实现分流，名单互斥。玄序自身不进入
  VPN，控制面 / DERP / UDP 外层套接字仍逐个保护。Rust 内核固定版本不变。
- 系统诊断只读本机权限、通知、电池、后台限制及版本；不把系统设置正常当成
  网络连通。仅在用户操作时打开系统设置、复制脱敏摘要，不自动申请电池豁免。

## Why

手机切换家庭和办公部署时不应每次重输服务器，也不能用删除应用数据切换账号。
部分应用不需要访问私网，应能明确排除；只需要一两个应用时可以使用允许清单。
厂商后台限制与 ACL、设备授权、网络连通是不同问题，诊断必须区分，不能伪报在线。

## Compatibility impact

- 不改服务端、TS2021 / Noise / Register / Map / WireGuard / Disco / DERP。
  服务端仍决定机器所属租户、可见节点与网络 ACL，不因选择应用而增加权限。
- 不添加默认路由、不修改手机 DNS，不声明已经实现系统级 MagicDNS、出口节点、
  Tailnet Lock、共享地址转换或手机子网转发。
- 同一根地址只保存一个配置，不把多账号误称为多个服务器；移除连接记录不删除
  私钥，重新添加原服务器仍复用原身份，也不等于退出账号或服务端撤销设备。
- 应用选择仅作用于当前 Android 用户可见的软件包，不跨个人 / 工作资料读取。
  Android 按 UID 选择流量，共享 UID 的包可能一起生效；不是应用安全沙箱或
  独立的人类 / 服务身份 ACL。
- 老偏好迁移保留原地址、设备名与两个开关，默认应用策略仍是全部应用。
  无机器身份格式迁移，原有控制面哈希目录保持不变。

## Security impact

- Auth Key 仍只存内存；不进入偏好、软件包清单、诊断、URL 或构建产物。
- 应用清单只在选择页按需查询可启动及已选的软件包，不申请 `QUERY_ALL_PACKAGES`，
  不采集通讯录、上网历史或上传应用清单。Debug 的 shell 可见性声明不进入 Release。
- 仅所选模式不能保存空清单。连接前及每次建 TUN 时重新确认安装状态；允许清单
  全部失效时失败关闭，不能让 Android 的空允许清单变成“全部应用”。
- 允许清单不添加任何排除项；其他模式始终排除玄序本身。应用安装状态在检查后
  又变化时，Builder 失败，不能用半份应用配置建立隧道。
- 当前服务器不允许被移除；重复根地址、未知模式、非法包名、超量列表和损坏
  配置均拒绝，不静默覆盖身份或回退到另一服务器。
- 配置提交后无法读回真实当前项时，清除界面的旧服务器选择并要求重新加载；
  结果未知期间不能继续修改或连接，不用旧标签启动可能已切换的机器身份。
- 脱敏摘要使用白名单，不包含原生错误正文、授权 URL、服务器、IP、设备名或包名。
  仍含系统版本、网络类型、状态及计数，分享前请自行确认是否合适。

## Tests

- Dart 模型、控制器、Widget：分流默认值与未知模式、配置切换、连接中拒绝修改、
  空清单拒绝、修改设备名保留应用选择、小屏大字体固定保存、脱敏白名单和读取失败。
- Kotlin：规范根地址去重、16 项边界、当前项保护、模式互斥、应用卸载、拒绝自身、
  非法 / 超量包名，不允许空允许清单退化成全部应用。
- 真实 Android VPN：用模拟器其他 UID 的 TCP 验证允许、排除及恢复，验证原身份
  复用、子网恢复、应用消失拒绝；原 ICMP、ACL、DERP、切网、取消重连继续回归。
  验收结果以 `verification.md` 为准，不能把 Widget 测试替代真实 TUN 验收。

## 回滚与边界

新偏好保存在禁止备份的应用数据中；不要公开分享 shared_prefs 或私钥目录。
不要为了签名不兼容而在用户手机上自动卸载 App，因为那会删除机器私钥。
预览签名不一致时，用新的专用模拟器验收；真实手机需用户明确处理升级与身份撤销。

迁移成功后旧键已经移除，旧 APK 不认识新目录。回滚优先回滚代码但保留
`ProfileStore` 读取兼容层；不要自动还原旧偏好快照，也不要覆盖已使用的新身份。
本轮没有实现被系统杀进程后的自动拉起、物理蜂窝漫游保证或正式签名密钥托管。

上游行为依据：[VpnService.Builder](https://developer.android.com/reference/android/net/VpnService.Builder)
明确允许 / 排除互斥且空允许清单默认涵盖全部应用；
[软件包可见性声明](https://developer.android.com/training/package-visibility/declaring)
用于按需查询；未使用全软件包权限。
